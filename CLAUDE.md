# Repository Guidelines

This repository is used for R&D work spanning software, quantitative finance,
and related topics.

## Commits and pushes

- This is a public repository. Keep commit messages and PR descriptions short
  and to the point, do not pad them with extra detail or explanation.
- No emojis.
- No em dashes, in commit messages, code, comments, or docs.
- After pushing, tell the user which branch was pushed.

## Branching

- Work is split across branches by topic. Each branch generally corresponds
  to one distinct area of R&D work rather than mixing topics together.
